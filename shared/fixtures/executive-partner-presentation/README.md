# Synthetic executive partner presentation fixture

This 11-slide fixture uses the same synthetic Riverbend evidence base as the development impact report but applies presentation logic: one message per slide, a decision arc, fewer visible variables, speaker notes, and an explicit close.

Run `node build.mjs` to stage the complete deck specification in the operating system's temporary directory. Add `--render` to attempt PPTX generation when PptxGenJS is available. PDF export and slide rendering remain separate environment-dependent steps.
