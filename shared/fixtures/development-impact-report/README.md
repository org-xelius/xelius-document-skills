# Synthetic development impact report fixture

This fixture reuses the synthetic Riverbend evidence base in `../../example-content/`. It specifies a nine-page A4 report, representative image placeholders, a publication plan, and a pre-production QA record.

Run `node build.mjs` to stage a self-contained source project in the operating system's temporary directory. Add `--render` to attempt a PDF build when Playwright is available. Final binaries and renders are intentionally not committed.
