# Report Composition

## Page families

Cover, inside cover, acknowledgements, contents, foreword, executive summary, impact overview, section opener, one-column narrative, two-column narrative, photo-led narrative, case study, pull quote, metric dashboard, chart page, table page, recommendations, methodology, references, annex, and back cover.

Each family defines content capacity, grid span, typography roles, source zone, image behavior, and allowed exceptions.

## Rhythm

- Begin sections with orientation and a clear change in pace.
- Alternate dense analysis with open explanatory or visual pages when the evidence supports it.
- Avoid more than two consecutive pages with the same dominant composition.
- Use consistent running furniture but vary content silhouettes.
- Treat full bleed as emphasis, not default.

## Integrity

Keep headings with opening paragraphs, figures with captions, tables with titles and sources, and references with their sections. Repeat table headers and avoid row splits. Preserve meaningful whitespace and body-size minimums.

## Representative spread

Test:

1. A section opener
2. A narrative page
3. A chart, table, or visual page
4. An image-led page when relevant

Use the longest realistic title, densest note, and most complex data component. Repair the system before expanding.
