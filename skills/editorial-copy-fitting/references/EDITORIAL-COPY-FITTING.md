# Editorial Copy Fitting

## Transformation order

1. Remove duplicated context and throat-clearing.
2. Replace abstract nouns with active verbs.
3. Move secondary detail to captions, sidebars, notes, or annexes.
4. Compress examples while keeping the representative one.
5. Preserve the claim, denominator, time period, uncertainty, caveat, and source.
6. Split the component when honest compression is exhausted.

## Component jobs

- Headline: state the message.
- Standfirst: orient and motivate reading.
- Pull quote: preserve exact memorable language and attribution.
- Caption: explain what the reader should notice and credit the asset.
- Chart title: state the finding supported by the chart.
- Sidebar: hold related but non-linear detail.
- Slide body: support one spoken point.
- Speaker notes: hold evidence, nuance, transitions, and delivery cues.

## Transformation log

Record source text, fitted text, component, reason, evidence IDs, preserved caveats, substantive-change flag, and reviewer status.
