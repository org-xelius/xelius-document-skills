# Presentation Archetypes

| Archetype | Audience outcome | Common arc | Appendix role |
| --- | --- | --- | --- |
| Executive deck | decide or approve | context -> stakes -> evidence -> options -> recommendation -> decision | detail and sensitivities |
| Pitch deck | believe and commit | opportunity -> problem -> approach -> proof -> plan -> ask | diligence |
| Partner briefing | align and coordinate | shared context -> progress -> evidence -> gaps -> roles -> next actions | methods and workplan |
| Conference presentation | understand and remember | question -> tension -> discovery -> implication -> takeaway | citations and technical detail |
| Training presentation | perform a skill | goals -> concept -> demonstration -> practice -> feedback -> application | reference material |
| Data presentation | understand a pattern and act | question -> evidence sequence -> interpretation -> implication -> action | definitions and full tables |

Set slide count from speaking duration, complexity, and delivery style rather than a fixed slides-per-minute formula.
