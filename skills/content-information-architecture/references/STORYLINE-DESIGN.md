# Storyline Design

## Communication sentence

Write: "By the end, **[audience]** should **[outcome]** because **[central takeaway]**."

## Build the arc

Choose the logic the audience needs:

- Context -> stakes -> evidence -> implications -> action
- Question -> analysis -> answer
- Problem -> causes or options -> recommendation
- Current state -> change -> future state
- Learning goal -> concept -> demonstration -> practice -> application

An agenda is navigation, not narrative. Every slide should answer the question raised by the prior slide or create the need for the next.

## Storyline record

For every slide record:

- Narrative purpose
- Message-led headline
- Primary message
- Dominant evidence or visual form
- Evidence IDs
- Previous and next logical links
- Speaker-note need

Open by establishing purpose, stakes, tension, or a useful question. Close by resolving it with a decision, action, synthesis, or productive next question.
