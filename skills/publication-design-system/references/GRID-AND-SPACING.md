# Grid and Spacing

Define the canvas, safe area, columns, gutters, baseline, spacing scale, and exceptions.

## Reports

- Use 6–12 columns depending on page size and density.
- Protect binding, print, and running-furniture zones.
- Establish a baseline rhythm that can absorb headings, figures, captions, and notes.
- Permit controlled full-bleed and breakout components only when the page family declares them.

## Presentations

- Use a stable widescreen safe area with equal left and right margins by default.
- Reserve footer and source-line zones before composing content.
- Change silhouette through column spans and media proportions, not arbitrary margin shifts.

## Spacing scale

Choose a base unit appropriate to the medium and expose named steps such as `space-1` through `space-8`. Components may use only named steps unless a documented optical correction is required.
