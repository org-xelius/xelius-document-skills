# Anti-patterns

Reject these patterns unless a documented content or brand reason overrides them:

- Generic purple-blue AI gradients, glowing brains, robot portraits, or circuit-face imagery.
- Excessive rounded cards, glassmorphism, pills, and dashboard chrome in static publications.
- Generic corporate stock-photo collages presented as documentary evidence.
- Decorative charts, false precision, truncated scales, and legends that require constant eye travel.
- Mixed icon families or icons used as filler.
- One visual style applied to every report archetype.
- Identical page or slide silhouettes repeated without narrative reason.
- Tiny text used to preserve an overcrowded layout.
- Report paragraphs transferred directly to slides.
- Missing credits, source lines, caveats, or image rights.
- A successful export treated as proof of visual quality.

Repair by returning to audience, evidence, medium, and communication purpose.
