# Typography

## Decision sequence

1. Inspect licensed brand fonts and available system fonts.
2. Assign roles before sizes: display, heading, body, data, label, note, code.
3. Set output-specific scales; do not reuse report sizes in slides.
4. Test real content, diacritics, numerals, citations, and the longest headings.
5. Record fallback stacks and licensing status.

## Report defaults

- Start body text near 9.5–11.5 pt for print and 11–13 px equivalent for screen-first paged media; adjust for x-height, line length, and audience.
- Target roughly 45–75 characters per line.
- Use 1.35–1.6 body line height.
- Keep caption and source text readable; never treat 6 pt as a rescue strategy.
- Use no more than two primary families unless a specialist data or code face is essential.

## Presentation defaults

- Start near 48–60 pt for deck titles, 30–40 pt for slide headlines, 22–28 pt for supporting headings, and 17–24 pt for body text.
- Test on a full-slide render at normal viewing size.
- Shorten or split content before shrinking text.
- Reserve condensed faces for short display use, never dense paragraphs.

## Fit rules

Do not orphan headings, split a figure from its caption, or allow one-line title boxes to wrap accidentally. Record any material copy changes through `editorial-copy-fitting`.
