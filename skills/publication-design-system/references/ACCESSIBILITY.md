# Accessibility

Treat accessibility as a production requirement, not a final decoration.

- Maintain logical reading order and heading hierarchy.
- Preserve selectable text in PDFs where possible.
- Add document language, title, bookmarks, tagged structure, and alt text when the production path supports them.
- Provide accessible data tables beside charts.
- Avoid colour-only meaning and low-contrast source lines.
- Use descriptive link text and validate destinations.
- Write concise alt text that communicates purpose rather than appearance alone.
- Mark decorative images as decorative in the target format.
- Record unsupported accessibility checks as limitations; never report them as passed.
