# Publication Design System

Define the design contract after structure is understood and before representative composition.

Select the authorized brand mode: preserve, extend, new, light modernization, or reusable system. Audit templates, protected assets, font licenses, and geometry. Do not invent logos, redistribute unlicensed fonts, or restyle locked templates.

Read [DESIGN-DIRECTION-PROFILES.md](references/DESIGN-DIRECTION-PROFILES.md). Load only decision-relevant references: [TYPOGRAPHY.md](references/TYPOGRAPHY.md), [COLOUR-AND-CONTRAST.md](references/COLOUR-AND-CONTRAST.md), [GRID-AND-SPACING.md](references/GRID-AND-SPACING.md), [ACCESSIBILITY.md](references/ACCESSIBILITY.md), [ANTI-PATTERNS.md](references/ANTI-PATTERNS.md).

Record protected, flexible, and prohibited decisions. Deliver direction, semantic tokens, typography/colour/layout scales, chart theme, and component rules as needed. `assets/design-tokens.template.json` supplies a starter shape, not a compulsory aesthetic.

Define roles for headings, body, captions, sources, spacing, charts, tables, icons, imagery, borders, furniture, and safe areas. Derive distinct report/presentation scales from shared semantics; page geometry is not slide geometry.

Test long headings, dense tables, source-heavy content, chart series, sparse layouts, and crops across at least three relevant layout families. Check contrast, non-colour encodings, print behaviour, and viewing distance. Avoid decorative charts, mismatched icons, generic gradients, and effects competing with evidence.

Approve direction before scaling; revisit only when real content exposes structural failure. With incomplete assets, preserve known identity, document system-font fallbacks/pending assets, and state limitations.
