# Chart Selection

| Analytical job | Prefer | Avoid |
| --- | --- | --- |
| Compare categories | ordered bars, dot plot | pie with many slices |
| Compare parts of a whole | stacked bars with few parts | areas when precise comparison matters |
| Show change over time | line, slope chart, small multiples | unordered bars |
| Show distribution | histogram, box or strip plot | average-only display |
| Show relationship | scatter plot, matrix | implying causality |
| Show flow | Sankey only when quantities and paths are meaningful | decorative flow ribbons |
| Show geography | map when location is analytical | maps for simple rankings |
| Show exact lookup | annotated table | crowded multi-series chart |
| Show milestones | timeline | evenly spaced events that were not evenly timed |
| Show process | ordered diagram | pseudo-quantitative chart |

## Report treatment

Permit more detail, small multiples, full notes, and accessible companion tables. Maintain consistent scales across adjacent figures.

## Presentation treatment

Reduce variables, enlarge labels, directly annotate the focal series, mute context, and split sequential arguments. Animation or progressive disclosure may support delivery but the static export must remain intelligible.
