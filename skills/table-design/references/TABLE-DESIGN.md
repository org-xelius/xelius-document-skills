# Table Design

## Decide

Keep a table when readers need exact values, multiple attributes, definitions, or lookup. Use a chart when shape, trend, or magnitude is primary.

## Structure

- Put the comparison dimension in rows when practical.
- Use short, unambiguous headers with units.
- Align text left and numbers by decimal or place.
- Use consistent precision; do not add false precision.
- Distinguish totals with spacing, rule, weight, or fill.
- Define missing, not applicable, suppressed, and zero values separately.
- Attach footnotes to exact cells or headers and keep the source line with the table.

## Page and slide behavior

Repeat headers on page breaks and avoid split rows. Use landscape or annex routing before tiny type. Presentation tables should show only decision-critical rows and columns; provide the full table separately.
