# v0.2.1 release evaluation

Four paired synthetic tasks were completed against immutable `v0.2.0`, using fresh Codex subagent contexts. The corrected candidate has no remaining observed regression within those tasks. This is a small forward evaluation, not a statistical or cross-agent quality benchmark.

## Installed footprint

| Measurement | v0.2.0 | v0.2.1 | Reduction |
| --- | ---: | ---: | ---: |
| Skills | 14 | 10 | 4 retired identifiers |
| SKILL body words | 6,581 | 2,185 | 66.80% |
| Description characters | 2,971 | 1,402 | 52.81% |
| Installed UTF-8 file bytes | 208,048 | 178,985 | 13.97% |

All three release targets pass. Body words exclude YAML frontmatter; bytes include every installed file. These measurements do not establish token savings.

## Paired observations

| Task | Baseline instruction words read | Candidate instruction words read | Observed outcome |
| --- | ---: | ---: | --- |
| Protected-copy fitting | 518 | 471 | Both preserve protected wording, six counts, period, sources, survey limits, and causal caveat within 60 words |
| Offline citation audit | 495 | 477 | Both find missing, duplicate, ambiguous, uncited, and malformed records without inventing fields |
| Chart/table selection | 1,620 | 680 | Both preserve exact lookup values and the missing February gap; editable HTML/SVG and reading-size inspection exist |
| Approved editable deck | 2,853 | 714 | Final runs preserve 11 slides, 26 native text objects, two shapes, all notes, copy, colours, and geometry; 204 source checks each |

These counts come from evaluator-recorded full file reads, including SKILL frontmatter and applicable references. Supporting schemas/templates and inspected code are counted separately in the [machine-readable results](v0.2.1-results.json). Baseline chart/table work additionally read 128 asset words; baseline deck work read 377 schema/template words. Command output/help, automatic host metadata, hidden caching, and total context were not instrumented. Tokens and complete task durations remain null. Different validation paths mean these are observed loads, not controlled token-efficiency scores.

## A failure that changed the release

The initial deck candidate preserved the editable source and honestly reported limited QA, but left a LibreOffice font substitution unresolved. The baseline recovered installed Arial, so release was blocked.

The candidate now includes conditional renderer-font recovery guidance and `check-pptx-fonts.mjs`. A fresh evaluator detected the substitution, used project-local font discovery configuration, recovered Arial without changing the source, and inspected all eleven final renders. The [initial candidate evidence](evidence/v0.2.1/editable-deck/initial-candidate/check-summary.txt) remains alongside the [corrected evidence](evidence/v0.2.1/editable-deck/candidate/check-summary.txt). Font-family normalization is heuristic; unusual names require review.

The chart/table candidate also detected duplicated extracted SVG labels during its own checks, repaired them, and reinspected the final exports. No source values changed.

## Other checks

- 33 automated tests pass with zero skips, including measured SVG geometry.
- Skills CLI 1.7.6 discovers exactly ten; all four retired selectors fail clearly. Every specialist installs completely on its own.
- Collection installation passes for Codex, Hermes, and Claude Code.
- Migration tests use real v0.2.0 files and cover four directories, dry-run/apply/repeat, missing skills, foreign names, symlinks, backups, and provenance-limited lock cleanup.
- A real nine-page report and eleven-slide deck render successfully from copied standalone skills and separate project dependencies. Native text and all speaker notes are checked.
- The primary agent inspected all twenty fixture surfaces and both contact sheets. The report fixture remains sparse/underfilled; it is a rendering-path fixture, not a premium publication exemplar.
- A separate table-only run read only the consolidated entrypoint and table reference, produced no chart or planning artifacts, preserved values, and correctly disclosed failed visual rendering.
- Dependency audit reports zero vulnerabilities in the tested lockfile.

## Limits and archived evidence

Behavioural runs used Codex, not live Hermes/Claude sessions. Visual comparisons were not blinded. Chart/table layouts differ in page count and placed width. Native PowerPoint editing/rendering, physical print/projection, screen-reader use, and PDF/UA certification were not tested. Synthetic claims were checked for preservation, not external truth.

The corrected standalone deck run supplies explicit surface review and check records, not a claimed canonical QA 2.0 pass. Canonical QA schema 2.0, render hashes, stale-check invalidation, and PDF expectations retain their independent regression coverage.

Text/JSON/SVG/HTML evidence is archived under `evidence/v0.2.1/`, with private machine paths normalized. Binary deck/PDF/render artifacts are identified by hashes in the results rather than committed to the repository. The fixed deck specification remains in the synthetic fixture; generative outputs may vary on repetition.
